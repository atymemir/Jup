# findbuddy

Отдельное приложение подбора преподавателей в Казахстане. Node.js 22.18+ и npm.

## Самостоятельный репозиторий

Исходники перенесены из `atymemir/PrepWeb/findbuddy` в [atymemir/Jup](https://github.com/atymemir/Jup). Этот каталог — корень отдельного приложения: здесь собственные `package.json`, lockfile, конфигурация Next.js, изображения, миграции 101–111 и тесты. Установка, сборка и запуск не требуют algₐ. Название репозитория пока не меняет бренд приложения.

```sh
npm ci
npm run dev
```

Каталог: `http://127.0.0.1:3100/findbuddy`, лендинг: `http://127.0.0.1:3100/findbuddy/landing`. Без Supabase локальный preview хранит тестовые аккаунты в `.data/`. Для настоящих аккаунтов создайте `.env.local` на основе `.env.example` и задайте настройки существующего проекта Supabase. Файл не попадает в Git. `npm run build` собирает только это приложение; `npm start` запускает его на том же порту.

Основной адрес: [jup-atymemirs-projects.vercel.app](https://jup-atymemirs-projects.vercel.app). Корень перенаправляет на лендинг `/findbuddy/landing`. Прежний адрес `https://tryalga.app/findbuddy` сохраняется через прокси. `basePath: "/findbuddy"` нужен для существующих ссылок, писем и маршрутизации. У приложения собственный Supabase-проект Jup (`dczeqfgnobizshqzucmw`). Пользователи algₐ остались в исходном проекте; в Jup нужна отдельная регистрация. Бренд пока не менялся. В существующем Vercel-проекте `findbuddy` для этого репозитория Root Directory — корень (`.` / пустое значение), Install Command — `npm ci`, Build Command — `npm run build`. Переменные окружения остаются в этом проекте Vercel; в репозитории их нет.

## Отдельный лендинг

`/findbuddy/landing` — самостоятельная презентационная страница findbuddy. Главный каталог остаётся на `/findbuddy`; существующие ссылки на занятия, кабинеты и возврат после входа продолжают работать. Внизу приложения есть ссылка «О findbuddy».

Лендинг включает выбор цели, формата и бюджета с переходом в каталог, пояснение пути до урока, интерактивную иллюстрацию занятия, отдельные входы для преподавателя и центра, FAQ и условия бесплатного пилота. Примеры интерфейса обозначены как иллюстрации; реальные преподаватели, отзывы и результаты не выдумываются. Страница не создаёт аккаунты и не принимает оплату.

## Локальный запуск отдельно

Из этой директории выполните

```sh
npm ci
npm run build
npm start
```

Откройте http://127.0.0.1:3100/findbuddy. Для разработки используйте `npm run dev`. Первый запрос создаёт базу PostgreSQL через PGlite в `.data/local`. Перезапуск сервера сохраняет данные. Запускайте один процесс на каталог данных. На Windows команды локального запуска можно выполнить в WSL.

Создание аккаунта проходит в три шага: роль → имя и необязательная дата рождения → почта и пароль. Вход без аккаунта и переключение деморолей отключены, включая серверный API. Новые преподаватели проходят ручную проверку. Ученику доступны приватный учебный профиль с готовыми ответами и ползунками, поиск, заявки, чаты и бронирование. Центр приглашает преподавателей и ведёт собственные направления и расписание. В локальном режиме платные записи можно оплатить условными тенге; реальные платежи не подключены. Комиссия платформы в пилоте — 0%. Для нового набора данных укажите новую директорию в `FINDBUDDY_DATA_DIR`. Локальная версия предназначена для одного компьютера; почта не подтверждается, служебный доступ при локальной регистрации не выдаётся.

В размещённой версии единственный владелец и модератор — аккаунт с подтверждённой почтой `dpsg2e@gmail.com`. Пароль не задаётся в коде. Миграция 111 назначает права существующему подтверждённому аккаунту или при последующем подтверждении почты. Предыдущие служебные роли и непринятые приглашения модераторов отзываются. Дата рождения хранится отдельно, с доступом только к собственным данным, и не включается в учебный контекст преподавателя.

Публичные инструкции: `/findbuddy/guide`, конфиденциальность: `/findbuddy/privacy`, правила пилота: `/findbuddy/terms`. Instagram: [@fin.dbuddy](https://www.instagram.com/fin.dbuddy/).

## Собственное размещение

1. Для текущего MVP используется отдельный проект Supabase Jup. Выполните в SQL Editor миграции из `supabase/sql/` по порядку 101 → 102 → 103 → 104 → 105 → 106 → 107 → 108 → 109 → 110 → 111 → `20261123175841_findbuddy_access_grants.sql`. Пропустите уже применённые миграции.
2. Скопируйте `.env.example` в `.env.local`, укажите URL и публичный ключ этого проекта в `.env.local` и в окружении сервиса FindBuddy на хостинге. Настройки основного сайта не наследуются отдельным сервисом. Укажите серверный `SUPABASE_SERVICE_ROLE_KEY` для Telegram. Браузерная сессия хранится отдельно (`findbuddy-auth`); аккаунты Jup принадлежат собственному Supabase Auth. Старый service_role от algₐ использовать нельзя. В Supabase Auth настройте URL сайта и разрешённые адреса перенаправления. Site URL: `https://jup-atymemirs-projects.vercel.app/findbuddy` (без точки в конце). Включите вход через email и добавьте `https://jup-atymemirs-projects.vercel.app/findbuddy/login**` и `https://tryalga.app/findbuddy/login**` в Redirect URLs. Для отправки писем пользователям настройте SMTP. Публичные переменные Next.js нужны до сборки.
3. Укажите эту директорию как корневую для размещения. Команда сборки — `npm ci && npm run build`. Для Node-хостинга запускайте `npx next start -H 0.0.0.0 -p 3000` за HTTPS-прокси. FINDBUDDY_PREVIEW оставьте выключенной. Подключённый Supabase хранит аккаунты и данные между перезапусками; анкеты преподавателей проходят ручную проверку. Локальный preview доступен только на localhost и запрещён на Vercel: файловая база в `/tmp` не сохраняет реальные аккаунты. Сборка Vercel без URL и публичного ключа Supabase завершается ошибкой.
4. Подтвердите аккаунт `dpsg2e@gmail.com` по инструкции в OPERATIONS.md. Владелец и модераторы проверяют преподавателей и центры в `/findbuddy/admin`.
5. Настройте бота по разделу «Telegram» ниже.
6. Приём банковских платежей и реальные выплаты отложены до выбора провайдера.

## Расписание и прямая запись

В кабинете преподавателя можно опубликовать индивидуальный час или мини-группу. Ученик выбирает свободный час в анкете или предлагает другой бюджет и время. Запись появляется в «Мои занятия». Там доступны чат и экспорт в календарь. Закрытие набора сохраняет брони, отмена отдельной брони освобождает место при открытом наборе.

## Проведение занятий

Кабинет преподавателя → «Добавить индивидуальный урок» или «Создать мини-группу» публикует одну дату или серию до восьми недель. Каждая дата бронируется отдельно. Если один час занят, вся серия откатывается. В «Моих занятиях» календарь показывает записи и опубликованные часы. Скачанный файл недели содержит напоминания за 15 минут. После переноса скачайте обновлённый файл. Автоматически обновляются календари внутри findbuddy.

Преподаватель заранее открывает «Материалы занятия» в расписании или работает с уже созданной записью. В комнате доступны план, ссылка на учебный материал, место встречи, итоги урока и домашнее задание. Для групп общий план виден всем записанным. Ответ ученика, проверка и чат доступны только ученику и преподавателю. Входящие сообщения, новые задания и переносы собраны в «Ждут вашего ответа». Время индивидуального урока меняется после согласия обеих сторон.

### Видеосвязь

Укажите серверные `FINDBUDDY_VIDEO_URL` (адрес `wss://` LiveKit), `FINDBUDDY_VIDEO_KEY` и `FINDBUDDY_VIDEO_SECRET` и перезапустите приложение. Подходит свой LiveKit или проект LiveKit Cloud. Для локальной проверки запустите `livekit-server --dev --bind 127.0.0.1` и настройте только в локальном окружении `FINDBUDDY_VIDEO_URL=ws://127.0.0.1:7880`, `FINDBUDDY_VIDEO_KEY=devkey`, `FINDBUDDY_VIDEO_SECRET=secret`. Для камеры и микрофона нужен HTTPS или localhost. [Документация LiveKit](https://docs.livekit.io/transport/self-hosting/local/)

Вход открывается за 15 минут до урока. Сервер проверяет действующую бронь и выдаёт короткий токен на конкретную комнату. У участников группы одна комната. Вход с выключенными устройствами, включение камеры, микрофона и демонстрации экрана по выбору участника. На вкладках чата и домашней работы звонок остаётся активным. Выход из занятия отключает звонок. Без видеосервера преподаватель может сразу использовать собственную ссылку на встречу или адрес аудитории.

В «Моих занятиях» можно создать личную ссылку для подписки на расписание. Вставьте её во внешний календарь как подписку по URL. Период обновления задаёт календарное приложение. Подписка содержит темы и время будущих занятий и историю за 90 дней. Ключ можно заменить или отозвать. Для облачных календарей нужен публичный HTTPS-адрес приложения.

Миграция 104 добавляет профили с фото, образованием и описанием первого урока. Фото принимаются как JPG, PNG или WebP, сжимаются до JPEG и публикуются вместе с подтверждённой анкетой. Удаление и замена фото доступны в редакторе профиля.

## Каталог и кабинет преподавателя

Каталог открывается на `/findbuddy`. Нажатие на карточку переворачивает её и показывает описание, опыт и действия. В режиме «По одному» можно листать анкеты кнопками или горизонтальным жестом. Избранное сохраняется в браузере. Примерные портреты отмечены в карточках и используются только для трёх демоанкет. Реальные анкеты показывают загруженные преподавателями фото.

Кабинет преподавателя открывается по `/findbuddy/teacher`. В обзоре видно ближайшее занятие. В расписании можно публиковать индивидуальные уроки и группы, готовить материалы, закрывать набор и настраивать подписку на календарь. В «Учениках» доступны личные чаты, занятия, переносы и работы на проверку. Заявки и публичная анкета открываются в отдельных разделах кабинета.

## Сообщения и сравнение

«Написать» в карточке или анкете открывает личный диалог до бронирования. В «Сообщениях» доступны непрочитанные, поиск и отдельный фильтр чатов занятий. Диалоги видят только их участники. Переписку можно приостановить в меню диалога. Если подключён Telegram, бот отправляет уведомление со ссылкой. Текст личного сообщения остаётся в findbuddy.

Сохраните хотя бы две анкеты и откройте «Избранное» → «Сравнить избранных». Сравнение показывает цену, ближайшее время, язык, формат и опыт.

После окончания забронированного урока ученик может опубликовать или обновить одну оценку преподавателя. История занятия даёт переход к форме в анкете. В каталоге отображаются реальные оценки. Отменённые записи исключаются, имя ученика и данные записи в отзывах не публикуются.

## Telegram

1. Примените миграцию `107_findbuddy_telegram.sql`. Создайте бота через [BotFather](https://t.me/BotFather).
2. На хостинге findbuddy задайте `FINDBUDDY_TELEGRAM_BOT_USERNAME`, `FINDBUDDY_TELEGRAM_BOT_TOKEN`, `FINDBUDDY_TELEGRAM_WEBHOOK_SECRET`, `SUPABASE_SERVICE_ROLE_KEY`. Для стенда с другим адресом задайте `FINDBUDDY_PUBLIC_URL` с путём `/findbuddy`. Пример есть в .env.example. Перевыкатите сервис.
3. Загрузите токен и тот же секрет вебхука в окружение терминала или в локальный .env.local внутри findbuddy. Выполните `npm run telegram:check`, чтобы проверить локальные настройки и сайт, затем `npm run telegram:setup`. Команда проверит имя бота, зарегистрирует вебхук и настроит меню команд. [Telegram Bot API](https://core.telegram.org/bots/api#setwebhook)
4. В веб-приложении откройте «Мои занятия» → «Подключить Telegram». Откройте личную ссылку, нажмите Start, затем в боте выберите «Мои занятия» или «Сообщения». Настройки уведомлений и отключение находятся в «Уведомлениях» в меню бота.

Для напоминаний задайте отдельный `CRON_SECRET` на сервере. Настройте планировщик, который раз в 5 минут вызывает `GET /findbuddy/api/findbuddy/telegram/reminders` с заголовком `Authorization: Bearer <CRON_SECRET>`. Напоминания приходят примерно за час и за 15 минут до начала. Без планировщика продолжают работать меню, привязка и уведомления о действиях.

Для проверки на стенде используйте два аккаунта. Привяжите бота ученику, отправьте ему предложение и личное сообщение, затем забронируйте занятие и проверьте открытие записи из Telegram. При проверке напоминания создайте запись в пределах следующего часа и запустите планировщик дважды. Повторный запуск сохраняет отметку об уже доставленном напоминании.

## Результат занятия и расчёты в бесплатном пилоте

Миграция `108_findbuddy_outcomes.sql` добавляет отдельные ответы ученика и преподавателя о проведении занятия. Примените её после 107 до размещения этой версии. Локальная preview-база обновляется автоматически при запуске нового процесса.

После окончания 60 минут в комнате занятия доступны подтверждение проведения и описание проблемы. Каждый меняет только свой ответ; ответы другого участника видны ему, но не публикуются в каталоге. Повторная отправка того же ответа не создаёт дубликат. Изменение из устаревшей вкладки требует обновления. Начавшуюся запись нельзя отменить через API, чтобы не терять историю; результат обсуждается в комнате.

Преподаватель открывает «Расчёты · пилот без комиссии» в обзоре или «Расчёты в пилоте» в меню аккаунта. В итог стоимости включены только завершившиеся записи с подтверждением обеих сторон. Участники мини-группы учитываются по отдельности. Комиссия платформы — 0%. Подтверждение проведения не подтверждает получение оплаты за урок.

## Бесплатный пилот

По решению владельца первый пилот FindBuddy бесплатен для участников. Стоимость уроков задают преподаватели; платформа не принимает реальные платежи и не собирает 5%. Будущий тариф 5% не активирован.

Перед размещением примените `109_findbuddy_free_pilot.sql` после 108. Миграция сохраняет прежнюю модель 5% в `model_commission` / `model_tutor_net` как иллюстрацию, а фактические поля `commission` / `tutor_net` становятся 0 / полной стоимостью урока. У каждой записи сохраняется `commission_policy='pilot_free'`. Будущий тариф нельзя применять к пилотным записям задним числом. Клиент не может менять эти условия через RPC.

## Возврат после входа и подтверждения почты

Выбранная запись, анкета или раздел передаются в проверяемом параметре `continue`, а условия каталога — отдельными разрешёнными параметрами. Работает и без `sessionStorage`. Произвольные URL, токены, пароли и параметры стороннего перенаправления не копируются в ссылки возврата.

Если используются письма Supabase, в Redirect URLs дополнительно разрешите параметры только у маршрута входа: `https://tryalga.app/findbuddy/login\?**`. Для собственного домена замените только origin. Это glob-шаблон с буквальным `?`; домен и путь фиксированы. Не используйте широкий wildcard для всего домена. Старые точные URL из инструкции выше остаются совместимыми для ссылок без контекста. Проверьте, что шаблон письма сохраняет переданный RedirectTo. [Настройка Redirect URLs и синтаксис glob в документации Supabase](https://supabase.com/docs/guides/auth/redirect-urls).

Проверяйте подтверждение и восстановление настоящим письмом на целевом стенде: локальные тесты параметров не подтверждают SMTP и настройки внешнего проекта.


## Кабинеты, анкеты и роли

Все пути ниже начинаются с `/findbuddy`:

| Путь | Назначение |
| --- | --- |
| `/student` | Занятия, поиск, личные сообщения и приватная учебная анкета |
| `/teacher` | Расписание, ученики, заявки, анкета, направления, участие в центрах |
| `/business` | Страница центра, команда по приглашениям, направления, даты и обращения учеников |
| `/admin` | Проверка анкет и центров, обращения, история; управление модераторами только владельцу |
| `/centers` и `/centers/[id]` | Проверенные центры, их команда, направления и занятия |
| `/teach`, `/for-centers` | Отдельные входы для преподавателей и центров |
| `/invite?token=…` | Принятие приглашения с проверкой роли, почты и срока действия |

Ученик указывает имя, этап обучения, класс/курс и цель перед первой новой записью. Место учёбы, город, срок, экзамен и предпочтения необязательны. Анкета не публикуется. Преподавателю и центру передаётся только ограниченная учебная информация при наличии своей записи; центр не видит личные диалоги преподавателя.

У преподавателя есть образование, сертификаты, владение языками, подход, аудитория и отдельные направления. У направления свои предмет, экзамен, языки, формат, город и цена. Конкретный урок может быть бесплатным (`0 ₸`) или платным. В бронь записываются условия выбранного урока; последующее редактирование не меняет историю.

Роль хранится на сервере. Обычный пользователь не превращается в преподавателя кнопкой или изменением метаданных. Для другой роли используется отдельная регистрация. Служебные роли не доступны при регистрации. Старые ссылки на кабинет и выбранную запись остаются совместимыми.

Контент анкет редактируется сейчас. Индивидуальный конструктор оформления карточек, сбор 5%, платёжный провайдер и загрузка частных документов в эту версию не входят.
