# Jup edu в Telegram

Бот: **@jup_edu_app**. Адрес Mini App после размещения этой версии:

**https://findbuddy-kohl.vercel.app/findbuddy/telegram**

Mini App использует те же аккаунты, анкеты, занятия и переписку, что и сайт. Первое подключение выполняется после обычного входа в Jup. Пользователь явно связывает свой аккаунт с текущим Telegram; при следующих запусках уже связанный аккаунт входит без пароля. Ссылка на урок или чат сохраняется и при первом входе по почте.

## Размещение

1. Разместить изменения в том же Vercel-проекте, который обслуживает `findbuddy-kohl.vercel.app`.
2. Оставить текущие `NEXT_PUBLIC_SUPABASE_URL` и `NEXT_PUBLIC_SUPABASE_ANON_KEY`. На этом же хостинге нужны серверные `SUPABASE_SERVICE_ROLE_KEY`, `FINDBUDDY_TELEGRAM_BOT_TOKEN` и `FINDBUDDY_TELEGRAM_WEBHOOK_SECRET` (случайная строка из букв, цифр, `_` и `-`). Значения секретов хранить в настройках хостинга, не в GitHub и не в переписке.
3. Задать публичные настройки: `FINDBUDDY_TELEGRAM_BOT_USERNAME=jup_edu_app` и `FINDBUDDY_PUBLIC_URL=https://findbuddy-kohl.vercel.app/findbuddy`. После изменения переменных перевыложить сервис.
4. Проверить `https://findbuddy-kohl.vercel.app/findbuddy/api/telegram/session`: `available` должно быть `true`. Ответ содержит только готовность и публичное имя бота.
5. В BotFather выбрать `@jup_edu_app` и задать адрес выше в настройках Main Mini App. Меню бота также настраивается командой ниже.
6. На доверенном компьютере с реквизитами того же бота в игнорируемом `.env.local` выполнить:

   ```sh
   npm run telegram:check
   npm run telegram:setup
   ```

   Настройка проверит соответствие имени бота токену, сохранит вебхук, команды (включая `/app`) и кнопку меню **Открыть Jup**. Токен не выводится в результат. Команда меняет настройки существующего бота; старые команды занятий и уведомлений сохраняются.

Новых SQL-миграций нет. Используются уже существующие функции и таблицы интеграции Telegram (`fb_telegram`, `fb_action`, `fb_link_telegram`) и таблицы аккаунтов Jup. Если старая интеграция ещё не размещена, сначала проверить и применить только отсутствующие миграции приложения; не перезапускать bootstrap существующей базы.

## Вход и привязка

- При первом открытии выбрать **Войти в Jup** или создать аккаунт. Подтвердить почту, если это требуется текущей настройкой проекта.
- После входа нажать **Связать с Telegram**. Уже связанный с другим аккаунтом Telegram нельзя незаметно переназначить.
- Далее вход использует только проверенные на сервере данные Telegram и ранее созданную связь. Новый пользователь по Telegram автоматически не создаётся, роль не назначается и не меняется.
- Для получения сообщений и напоминаний нужно начать личный чат с ботом (Start). Настройки уведомлений доступны в боте как раньше.
- Отключить Telegram можно существующей командой бота или в кабинете Jup. Уже открытый сеанс Jup остаётся обычным сеансом аккаунта; для его завершения нажать **Выйти**. Повторный вход через Telegram без привязки прекращается.

Сервер проверяет HMAC `initData`, возраст до пяти минут, отсутствие дублирующихся полей и Telegram ID. Он ищет существующую связь, проверяет подтверждённую почту, получает обычный сеанс через серверный Supabase Admin magic-link exchange и проверяет связь ещё раз перед выдачей сеанса. Письмо с magic link при этом не отправляется; Supabase Auth не перенастраивается. Смена связи во время входа приводит к отзыву нового сеанса. Ограничение попыток в памяти — дополнительное ограничение на экземпляр сервера, а не распределённая квота.

SDK `initDataUnsafe` не используется для входа. Произвольные URL в параметре запуска не принимаются. Приватные данные по-прежнему защищены существующими серверными проверками и RLS.

## Проверка на реальном устройстве

После настройки бота проверить Telegram на iOS и Android: первый вход и привязку, повторное открытие, переход из уведомления к уроку/чату, кнопку «Назад», закрытие редактора через неё, появление клавиатуры, безопасные отступы, отправку файлов и разрешения камеры/микрофона для видеосвязи. Автоматические браузерные проверки используют имитацию SDK; они не заменяют проверку клиента Telegram и живых реквизитов.
