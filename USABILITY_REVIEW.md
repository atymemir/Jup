# Проверка удобства Jup

Изменения касаются интерфейса и загрузки приложения. Маршруты `/findbuddy`, серверные проверки ролей, Supabase Auth и схема базы сохранены.

- Верхние панели каталога и кабинетов прокручиваются вместе со страницей. Боковая навигация и мобильное нижнее меню остаются доступны.
- Карточки преподавателей показывают квадратную область фото целиком. Новые загрузки вписываются в квадрат без обрезки, с нейтральными полями для вертикальных и горизонтальных снимков. Если старый файл уже был обрезан при загрузке, восстановить его края можно только повторной загрузкой оригинала.
- Анкета создаётся в два шага: быстрый выбор предмета, готовые начальные значения, заполнение основы описания одной кнопкой с отменой. Подробные сведения раскрываются отдельно. Enter переводит на следующий шаг; проверка полей возвращает к нужному шагу.
- Админка: поиск, счётчики и фильтры статусов, корректные пустые состояния для каждого раздела. Переход между преподавателями и центрами закрывает предыдущую проверку. Изменившаяся анкета требует обновить проверку; фотография перечитывается вместе с её версией. Действующая политика доступа владельца сохранена.
- Разделы кабинета и комната урока загружаются по необходимости. Одновременные одинаковые чтения объединяются только для публичного каталога или одного явно определённого сеанса. Ответы после завершения не кэшируются. Фоновые обновления кабинета происходят реже и пропускаются во время заполнения формы; неизменившиеся снимки данных не перерисовывают весь кабинет.
- Лендинг получил контрастные секции, быстрый выбор ЕНТ/SAT/IELTS/школьной программы и переход к Telegram. Основные кнопки приведены к высоте 48 px. Новые тексты переведены на казахский и английский.
- Экран загрузки упрощён до небольшого индикатора и подписи. Убраны карточки-заглушки и раскрывающаяся полоса. Кабинет сохраняет каркас навигации во время загрузки; каталог резервирует место под результаты. `body` предотвращает схлопывание верхнего отступа и сохраняет высоту экрана, чтобы смена загрузки не сдвигала всю страницу. Добавлена своя страница 404 с переходами в каталог и справку на трёх языках.

## Проверки перед размещением

`npm run build`, `npm run lint`, `npm test`.

В браузере: лендинг и фильтры, каталог, отсутствие горизонтальной прокрутки на узких экранах, создание анкеты с вертикальным фото, отправка на проверку, поиск и фильтры админки, решение с записью в историю, обновление устаревшей проверки, HTTP 404 и переходы со страницы ошибки, упрощённая загрузка при задержке API. Сдвиги разметки проверяются через PerformanceObserver на каталоге, анкете и админке. Сценарии записи выполняются только в отдельной локальной базе с тестовыми аккаунтами.

На реальном устройстве после размещения проверить прокрутку с открытой клавиатурой и навигацию внутри Telegram на iOS и Android. Производственные реквизиты в облачном окружении отсутствуют; готовность живой базы и интеграций проверяется на хостинге.
